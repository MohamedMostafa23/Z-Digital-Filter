# Z Digital Filter

An educational Flask and JavaScript app for exploring digital filter design. The interface lets you place zeros and poles and inspect how the filter changes the signal and its frequency response.

- [Flask signal-processing code](app.py)
- [Browser visualization](static/js/chart/chart.js)
- [Example ECG input](https://github.com/MohamedMostafa23/Digital-Filter/blob/main/Data-Nor-ECG.csv)

The original app uses the example ECG CSV as its input.
